# 모노크롬 나인 이스케이프

방향키만으로 도망 다니는 탄막 회피 게임입니다. 브라우저에서 바로 돌아갑니다.

**플레이: https://minaritime.github.io/monochrome-nine-escape/**

## 이름

레인보우 식스 시즈를 통째로 뒤집었습니다. Rainbow ↔ Monochrome, Six ↔ Nine(6을 뒤집으면 9),
Siege ↔ Escape. 농담으로 지었는데 실제로 맞는 이름이 됐습니다. 저쪽은 마우스로 조준하고
팀을 짜서 거점을 치는 게임이고, 이쪽은 마우스가 아예 없고 혼자서 사방에서 몰려오는 것을
피해 다닙니다. **조준의 반대가 자동 타겟팅이고, 공성의 반대가 회피입니다.**

## 조작

| 키 | 동작 |
|---|---|
| 방향키 | 이동 (WASD 는 안 씁니다) |
| Q | 유틸 스킬 |
| Esc | 일시정지 |
| 1 / 2 / 3 · R · S | 레벨업 선택 · 리롤 · 건너뛰기 |

**조준 조작이 없습니다.** 기본공격도 공격 스킬도 전부 자동으로 대상을 고르고 자동으로
나갑니다. 손으로 쓰는 것은 유틸 스킬 하나뿐입니다.

**마우스와 터치는 지원하지 않습니다.** PC 브라우저에서 키보드로 하는 게임입니다.

## 무엇이 들어 있나

- 적 14종 + 정예 + 보스 3종. **색은 위험도, 모양은 행동 유형**이라는 규칙으로 그렸습니다
- 스킬 14종. 공격 스킬은 6레벨에서 두 갈래 중 하나를 고릅니다 (24갈래)
- 난이도 -1 부터 15 까지. 아래를 깨야 위가 열립니다
- 도감 · 기록 · 업적 53개 · 코인 상점
- 이미지도 사운드도 없이 전부 도형으로 그립니다

## 저장

기록은 브라우저의 `localStorage` 에 남습니다. 로그인이 없어서 **컴퓨터마다 따로 쌓입니다.**
집에서 딴 업적은 다른 컴퓨터에 안 따라옵니다.

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm run check     # 타입 검사 + 로직 점검 + 부팅 점검 (브라우저 없이)
npm run build     # 프로덕션 빌드
```

`npm run check` 가 브라우저 없이 게임 전체를 돌려봅니다. 14분 자동 플레이, 적 14종 단독
동작, 스킬 16종 발동, 난이도 표 검산, 부팅부터 게임오버까지의 화면 전환까지 봅니다.

설계 기록은 `기획.md` 와 `CLAUDE.md` 에 있습니다.
